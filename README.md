## Selected work

- **PIX with credit card (PicPay).** We shipped PIX payment and scheduling with credit card across four teams. I helped define the scope and architecture. Product measured a ~50% increase in sales conversion.

Processing went from 15 minutes to under 3 (82% faster), and the row limit from 3,000 to 300,000. Persistence is idempotent, so duplicate messages never create duplicate data.
- **Identity migration (Pravaler).** Helped move user management from an OpenID Connect login to Google Cloud Identity Platform, as part of a company-wide move to GCP.
